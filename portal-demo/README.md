# 全原生控制台 / 客户门户静态演示（GitHub Pages）

视觉与信息架构对齐真实 Oh My CPA 控制台（同一套主题 token、侧栏分组、页面密度）。  
**唯一差别是权限：**

| 角色 | 登录后 | 侧栏 |
| --- | --- | --- |
| 管理员 | 原生控制台壳 | 运行 / 网关（含**客户账户**）/ 观测 / 插件 / 控制 |
| 客户 | 客户门户壳 | 概览 / API 密钥 / 使用记录 / **钱包** / 账户（无管理菜单） |

客户侧演示能力：

1. **概览** — 近 14 日请求 / Token / 费用趋势图 + 网关 Base URL / 鉴权头 / curl 示例  
2. **API 密钥** — 创建 → 一次性明文弹窗 → 复制 → 撤销确认；状态标签（可用 / 已撤销）  
3. **使用记录** — 按密钥 / 模型 / 成功|失败筛选；点击行展开延迟与错误  
4. **网关接入** — 概览页固定面板  
5. **钱包** — 余额、兑换码、流水（演示数据）

- 全部为**演示数据**，不连接真实 CPA  
- 推荐：`admin` / `demo`（管理员），`trial` / `demo`（客户）

在线：https://ibi6.github.io/oh-my-cpa/portal-demo/?v=customer-rich
